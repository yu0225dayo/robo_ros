==============================
 起動手順 (計算機上)
==============================

【ステップ1】 SAM-6D Docker イメージのビルド (初回のみ)
  cd ~/ws/robo_ros/server
  docker compose build sam6d

【ステップ2】 SAM-6D Docker サービスを起動
  cd ~/ws/robo_ros/server
  docker compose up -d sam6d

  # ログ確認 (モデルロードに数分かかる)
  docker compose logs -f sam6d

  # ヘルスチェック
  curl http://localhost:8081/health

【ステップ3】 把持統合サーバ (server_grasp.py) を起動  ★現在の推奨
  conda activate sam3d-objects
  cd ~/ws/robo_ros/server
  python server_grasp.py \
    --sam6d-service http://localhost:8081 \
    --host 0.0.0.0 \
    --port 8082

  # ヘルスチェック
  curl http://localhost:8082/health

  ※ server_grasp.py は SAM-3D + SAM-6D + Shape2Gesture を一括提供する。
     メッシュ生成・姿勢推定・把持姿勢生成をこのサーバ1本で処理する (port 8082)。
     server.py (port 8080) は不要。

  ※ デフォルトで以下を使用 (すべて ~/ws/robo_ros/server/ 内で解決):
     client/save_model        … server/client/save_model (symlink → ../client)
     sam2_checkpoints/        … server/sam2_checkpoints/
     sam-3d-objects/          … server/sam-3d-objects/

==============================
 API エンドポイント一覧 (server_grasp.py / port 8082)
==============================

  GET  /health                      → サーバ死活確認・モデルロード状態
  POST /generate_grasp              → PLY メッシュから把持姿勢生成のみ
  POST /estimate_and_generate_grasp → メッシュ生成 + 姿勢推定 + 把持生成 (フルパイプライン) ★推奨
